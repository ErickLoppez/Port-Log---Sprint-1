# Port Log

## Sprint actual

Sprint 3

## Objetivo

Aplicar conocimientos de bases de datos relacionales con SQLAlchemy, versionado de datos con DVC y búsqueda por similitud visual con ChromaDB para profesionalizar el sistema portuario.

## Introducción y contexto

El sistema portuario ha crecido en volumen y complejidad. Durante el Sprint 3 se incorporará persistencia estructurada mediante una base de datos relacional, versionado de datasets para mantener trazabilidad sobre los datos utilizados y búsqueda por similitud visual para identificar buques cuando el reconocimiento OCR no resulte suficiente.
