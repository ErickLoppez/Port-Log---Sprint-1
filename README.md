# Port Log

## Sprint actual

Sprint 2

## Objetivo

Aplicar conocimientos de tratamiento de imágenes y programación limpia sobre el sistema portuario, con el objetivo de determinar qué infracciones cuentan con evidencia visual válida.

## Introducción y contexto

Los radares ubicados en los accesos a los muelles registran infracciones de velocidad y las cámaras asociadas capturan evidencia fotográfica de los buques.

Las imágenes pueden corresponder a recortes de matrícula o a imágenes completas del buque. Sin embargo, no todas las infracciones poseen imágenes asociadas y algunas capturas pueden presentar problemas como desenfoque, baja iluminación o gran distancia.

Durante el Sprint 2 se analizarán estas imágenes junto con los datos procesados en el Sprint 1 para determinar qué infracciones disponen de evidencia visual válida.
