# Port Log - Sprint 1

## Sprint actual
Sprint 1

## Objetivo
Aplicar conocimientos de versionado, organización y análisis exploratorio de datos con pandas sobre un dataset real de operaciones portuarias.

## Introducción y contexto
El Puerto Fluvial de Rosario registra movimientos de buques con información proveniente de un sistema heredado. El objetivo de este sprint es organizar, analizar, limpiar y normalizar estos datos para poder utilizarlos de manera confiable en un nuevo sistema.
